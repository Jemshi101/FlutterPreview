# Flutter Preview sample

A small Flutter package for trying the [Flutter Preview](https://github.com/Jemshi101/FlutterPreview) plugin.
Its widgets and previews also produce the images on the plugin's Marketplace page.

```sh
cd sample
flutter pub get
```

Open this folder in Android Studio (with the plugin installed), then open any file in `previews/`.

* `previews/widgets/widgets_previews.dart`: cards, buttons, tiles and a dialog, in light and dark, with a text-scale
  variant and one preview that overflows on purpose, to show the problems panel.
* `previews/screens/settings_page_previews.dart`: a full page at a phone size taken from a constant.
* `previews/showcase/showcase_previews.dart`: compositions used for the Marketplace images.
