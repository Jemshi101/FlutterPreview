See your Flutter widgets while you write them, right inside Android Studio and IntelliJ IDEA, without a browser, an emulator or a running app.

Flutter Preview renders the @Preview functions of the Dart file you're editing with the same headless engine your widget tests use (flutter test), and shows them in a tool window. Real fonts, real assets, your theme and your wrapper are all included, and the previews re-render when you save.

Features

  • Whole-file rendering. All previews in the focused file render in one run and are cached, so switching between them is instant. Saving re-renders in the background, and the last good images stay visible while the code doesn't compile.
  • Single view with zoom: zoom in and out, 100 %, fit all, fit width and fit height. ⌘/Ctrl + mouse wheel also zooms.
  • Grid view of every preview in the file, with adjustable thumbnail size.
  • Layout problems at a glance. Overflows and other errors are listed under the image instead of breaking the render.
  • Copy Image / Save Image As… for pull requests, tickets and docs.
  • Editor integration (with the Dart plugin):
    • a gutter icon on every @Preview, and the selection follows the caret;
    • Alt+Enter → Create @Preview for this widget, with placeholder arguments;
    • Right-click → Generate Flutter Preview…, which adds a preview for the widget under the caret to a new or existing file in your previews/ folder.
  • Works with real apps. @Preview arguments such as size: kPhoneSize are evaluated in Dart. Native plugin calls (wakelock, shared_preferences, MethodChannels…) that nothing answers are stubbed. A local, gitignored .flutter_preview/setup.dart can initialise singletons or mock channels.
  • Light on memory. Nothing stays running between renders: memory is used only while a render runs.

Getting started

  1. Run flutter pub get in your Flutter package.
  2. Add a preview (import 'package:flutter/widget_previews.dart';): 
    @Preview(name: 'Status tile', size: Size(360, 120))
Widget statusTilePreview() => const StatusTile(label: 'Online');
    or right-click a widget and choose Generate Flutter Preview….
  3. Open View → Tool Windows → Flutter Preview.

Requirements

  • Android Studio 2026.2 or IntelliJ IDEA 2026.2 (build 262) or newer.
  • A Flutter SDK. The package must have run flutter pub get.
  • Optional: the Dart plugin, for the editor integration.
